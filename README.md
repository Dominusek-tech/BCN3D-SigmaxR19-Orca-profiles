# BCN3D-SigmaxR19-Orca-profiles
This repository contains BCN3D Sigmax R19 3D printer profiles for OrcaSlicer.\
## Bundle contains:
Separate printer profiles for each printing mode:
- only left toolhead 
- only right toolhead 
- duplication mode 
- mirroring mode 
- dual printing 
All modes were tested and work (yes, dual printing works, you read that right), but you will need to adjust print settings (like speed, flow ratio, etc.) to your particular printer.\
Included filament profiles:
- PET-G 
- ABS 
You can create more profiles based on these 2 or on generic orca profiles (remember to change the filament diameter!).\
Only one 0.15mm print profile added, but you can easily modify it to your needs.\
Build plate STL extracted from official Stratos AppImage. You can add it to printer profiles once imported to have a visual model of the bed, but it's not necessary.
